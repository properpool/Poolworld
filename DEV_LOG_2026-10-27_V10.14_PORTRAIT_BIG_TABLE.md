# Pool World v10.14 — portrait full-table focus and rotated touch safety
Date: 27 October 2026 (UTC). Development only. Production release remains blocked.

## Reproducible user-visible problem
The default 1100x570 table fits beside a 60px power control on a 360–412 CSS-pixel-wide portrait phone. This reduces the 24.4-table-unit ball diameter to fewer than 10 CSS pixels, making visual targeting and cue aiming difficult. This is a viewport geometry issue, not a measured physical Samsung performance result.

## Correction
An optional BIG TABLE button on portrait phones opens a virtual-landscape full-table focus view with the **same live canvas and existing match state**. The button does not appear on native landscape/desktop. The rotated view expands ball diameter by at least 1.7x on the four tested portrait sizes without stretching the canvas. EXIT BIG TABLE restores the original layout; rotation to native landscape also exits focus. Pointer coordinates use the inverse 90-degree transform, near-cue touch guards use the correct unrotated width, and fine aiming follows the local table axes. Power gestures follow the local track direction; normal unrotated power calibration is preserved exactly. The existing six pockets, physics, match rules, audio URI bytes, and production main/index.html are unchanged.

## Release gate
Automated Chromium viewport/touch tests are not independent physical Samsung Galaxy A37 or human acceptance. The physical reports of weak shots, jerky motion, awkward aiming and disappointing overall visuals remain unresolved. This correction increases table size in an **optional** portrait view, but does not establish improved physical FPS, smoothness or shot feel. Do not promote to production without independent physical-device/human acceptance and explicit user approval.
