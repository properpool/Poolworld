## Gameplay correction
A short-lived `postHitchTail` state records when a frozen isolated pause was discarded and one slower callback followed. If the **next** callback is ordinary (<50ms), its leftover accumulator is cleared before advancing only that callback's elapsed time. If the next callback is slow again, the marker is cleared without discarding debt, retaining the existing sustained low-FPS catch-up behavior. The marker is also cleared by new-shot, reset, restore and shot-resolution transactions.
