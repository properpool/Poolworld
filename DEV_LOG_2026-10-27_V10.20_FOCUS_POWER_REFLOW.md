# Pool World v10.20 — BIG TABLE power-slider reflow integrity

**Date:** 27 October 2026. **Branch:** `development/poolworld-match-engine` only. **Production:** untouched.

## Reproduced user-visible defect

On portrait phones, entering BIG TABLE reparents the table and power control into a rotated landscape overlay. The power track grows substantially, but the slider thumb and coloured fill retained their *old* pixel positions from the narrow portrait layout. The displayed number (for example, 75%) and authoritative `shotSpeed(75)` were correct, yet the thumb appeared at a much weaker position. Changing the viewport or browser chrome could also resize the track without updating its thumb.

The new mandatory Chromium suite `tests/test_pool60_focus_power_reflow.py` covers four portrait sizes (360×800, 390×844, 412×915, 375×667) and 25%, 45%, 75%, 95% selections, checking geometry on entry/exit, unchanged calibrated impulse, untouched ball and match state, and live track resizing.

- **Test-only run #421:** existing suites passed; the new suite was not yet registered.
- **Deliberately failing baseline run #422:** 108/128 new checks passed; 20 failed, including all 16 BIG TABLE entry alignment cases and four live-resize cases. Existing suites remained green.
- **Fixed staging candidate run #423:** 128/128 new checks passed; the full mandatory workflow succeeded. Jobs and decoded logs were inspected.

Representative baseline at 390×844, selected 75%: focused track height **219 CSS px**, correct thumb coordinate **156.16 px**, but the old thumb remained at **69.21 px**. This is a control *presentation* defect, not evidence of a changed cue impulse.

## Correction

- After entering or leaving BIG TABLE, synchronously recompute the thumb and fill positions using the **current** track height before rendering.
- Observe later track-size changes using `ResizeObserver`, recomputing visual geometry without changing the selected power, shot speed, shot state, physics, match rules, or audio.
- The existing relative power pull, quick-release shooting, touch capture and 5–100% strength curve remain unchanged.
