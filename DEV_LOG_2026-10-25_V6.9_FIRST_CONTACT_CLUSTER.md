# Pool World v6.9 — swept first-contact attribution in clustered shots
Date: 2026-10-25 (UTC)
Repository: properpool/Poolworld
Branch: development/poolworld-match-engine

## Defect and correction
The engine formerly recorded the first object ball hit by the cue according to its index in the balls array when multiple cue/object overlaps occurred in the same 120Hz physics tick. In tightly clustered layouts, array order need not match the actual time at which the moving cue first reaches a ball. This could produce an incorrect first-contact ruling.

The v6.9 candidate stores the start-of-step positions, calculates the relative swept-circle time of contact for each object ball, and records the earliest valid cue contact. Existing overlap/impulse resolution remains in place, and the previous contact assignment is retained as a fallback for overlaps arising only during collision correction. This changes first-contact attribution, not the sequential order of collision impulses; a later pass should investigate impulse-order dependence in near-simultaneous contacts.
