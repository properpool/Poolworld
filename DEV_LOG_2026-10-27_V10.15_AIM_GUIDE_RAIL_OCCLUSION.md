# Pool World development — v10.15 cue-guide cushion occlusion (27 October 2026)

## User-visible defect reproduced
The aiming guide selected an object-ball collision before checking whether the cue-ball centre would hit a cushion first. A grazing ball can remain wholly inside the cloth while its expanded collision circle lies *beyond* the cue centre's legal path. The old guide drew through the rubber and displayed a ghost-ball contact that could not happen, misleading precise aiming.

Reproduction: cue centre (467.2689115, 155.5734480), object centre (625.5305953, 97.6940476), aim -0.4944910431 radians. The old guide reached the object at 163.375 table units, but the first cushion is at 137.749 units. Mirrored top, bottom and left-cushion cases also reproduced.

## Fix
Only the aim-guide geometry in `POOL_WORLD_6.0_STAGING_MATCH.html` and the exact promoted branch-root `index.html` changed. Compute the first cushion distance before evaluating expanded-ball intersections; accept only nonnegative object contacts that occur strictly before that cushion. Preserve the old guide drawing, reachable ghost-ball indication, calibrated shot impulse, all match rules, six-pocket physics, visual assets and original audio. No changes to the simulation or actual shot power.

Mandatory browser regression: `tests/test_pool60_aim_guide_rail.py`, registered in `.github/workflows/poolworld-staging-tests.yml`. Four viewports (360x800, 390x844, 412x915, 1280x800) cover top/bottom/left cushion occlusion, reachable straight and diagonal contacts, unobstructed rail, ghost-ball visibility, stable aim angle, unchanged 100% shot impulse and no JavaScript exceptions. 80 checks total.
