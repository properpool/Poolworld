# Pool World 3.4 — Fair-play doubles fix

A local HTML build named `POOL_WORLD_3.4_FAIR_PLAY_DOUBLES.html` was created in the conversation working environment. It is **not** yet deployed to GitHub Pages.

## Fix
- Ordinary singles/doubles matches previously exposed a `MOVE WHITE` button that allowed repositioning the cue ball without a foul.
- The new local build guards this action: cue-ball placement is allowed only when `match.ballInHand` is true.
- The control now reads `BALL IN HAND ONLY` outside a foul.
- Existing singles and local 2v2 doubles controls were retained.

## Checks
- Extracted JavaScript passed `node --check`.
- Basic static checks verified the fair-play guard and doubles state remained present.
- Full-match browser tests and Android touch tests have **not** yet been completed.

## Release gate
Preserve existing live `index.html` until the tested 3.4 build is safely imported, regression-tested and verified in a browser. This note does not imply that 3.4 has been published.
