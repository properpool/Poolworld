# Pool World — v6.4 foul-recovery action and staging acceptance

Date: 25 October 2026. Repository: `properpool/Poolworld`. Branch: `development/poolworld-match-engine`.

## Reproduced usability risk and implemented correction
A legal rules foul previously set `ballInHand=true`, and `updateHUD()` disabled the SHOOT button entirely until a table tap placed the cue. This could feel like the reported "SHOOT stops working after a few shots" even though the engine was waiting for ball-in-hand placement. This is a verified UI dead-end in the code; it is **not** proof that it explains every historical user complaint.

Changed `POOL_WORLD_6.0_STAGING_MATCH.html` so the main button stays enabled and clearly reads **PLACE CUE** during ball-in-hand. Tapping it confirms a legal current cue position without firing; if the cue overlaps another ball or lies outside the valid placement region, the game finds a legal open position first. The button then returns to **SHOOT** for the next intentional tap. The player can still reposition by tapping the cloth. Engine `shoot()` continues to refuse firing while `ballInHand` is true, so the correction cannot bypass the foul rule. Status text explicitly describes both placement methods.

## New browser regression
Added `tests/test_pool60_foul_action.py` and required it in `.github/workflows/poolworld-staging-tests.yml`. Chromium touch tests at 390×844 and 844×390 verify: a real physics no-contact shot produces a foul; enabled PLACE CUE replaces the blocked SHOOT action; placement confirms without firing; the following SHOOT actually fires; scratch placement is available; illegal cue overlap is repaired; tapping the table still repositions the cue; no JavaScript errors. **18/18 checks passed** on GitHub Actions #95 and #96.

Updated the prior regression `tests/test_pool60_regression.py` to reflect the intentional UI change. The old assertion expected the button to be disabled on a scratch; the new assertion verifies the enabled PLACE CUE label while direct engine shooting remains prohibited.
