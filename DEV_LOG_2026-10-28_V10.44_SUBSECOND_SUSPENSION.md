# Pool World v10.44 — sub-second mobile shot suspension safety

**Date:** 28 October 2026 (UTC)  
**Scope:** Development-only moving-shot frame timing. Production is release-blocked.

## Reproduced user-visible defect

A short 620–940ms pause in browser animation callbacks (for example, a brief
phone system overlay or app interruption) was not covered by the existing
>1-second suspension guard. The game treated the returning callback as a
250ms physics frame, immediately ran eight 120Hz simulation ticks, then
retained roughly 0.18–0.19 seconds of simulation debt. The next 60Hz frame
spent another eight ticks catching up.

On the unchanged development baseline, one 75%-power fixture jumped
25.85 table units on the first resumed frame and 25.55 more on the next.
At 25% power, the corresponding fixture jumped 10.45 then 10.19 units.
This is an observable browser-render defect, not a measured Samsung FPS.

## Corrected implementation

Only the already established suspension guard's duration threshold changed:
`rawElapsed>1` became `rawElapsed>=.6` for an *existing* moving shot.
A gap of 600ms or more now discards suspended simulation time, clears
stale accumulator debt and aligns the previous visual pose to the current
authoritative ball position. A newly fired shot within 50ms of the
returning frame retains its actual post-input physics time.

The established 500ms isolated-hitch tests, sustained 3–14fps pacing,
fixed 120Hz physics, calibrated power, collisions, six pockets, complete
matches, graphics and four approved v3.9 audio URIs are preserved.

Passing staging blob: `6126c4348e5a9f6d7c036be07913d675bb984b37`.
The exact blob was promoted to development branch-root `index.html`
in commit `1b107ebf49ea36df064cf1d92e3d7934a1feaed5`.

**Production `main/index.html` was not modified.**
Its last verified blob was `011657038a72ff255297ca78f595eef0e67df1e3`.

## Release limitation

Chromium synthetic timestamps cannot establish actual Samsung Galaxy A37
FPS, touch latency, shot feel, graphics quality or human acceptance.
Independent physical Samsung testing and explicit user approval remain
mandatory before any production promotion. No unfinished-build testing
is requested from the user.
