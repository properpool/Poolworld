# Pool World v10.1 — Six-pocket squared-distance capture (26 October 2026)

## Problem and scope
The 120Hz physics loop tested every active ball against all six pocket centres using `Math.hypot(dx,dy)`, taking six unnecessary square roots per ball per physics tick. The capture rule was already a circular distance threshold; comparing squared distance to a precomputed squared radius is algebraically equivalent for finite game coordinates.
